# SEO Skill

## Technical SEO
- One clear H1 per page
- Proper H2/H3 hierarchy
- Semantic HTML
- Descriptive metadata
- Internal linking
- Clean URL structure
- Schema markup where appropriate
- Descriptive alt text

## Performance
- Optimize LCP
- Optimize CLS
- Compress images
- Lazy-load non-critical assets
- Minimize unnecessary JavaScript

## Local SEO
- Use location-based keywords naturally
- Include business contact information
- Add schema markup where appropriate
- Optimize Google Business Profile integration

## Content
- Clear readable copy
- Conversion-focused headlines
- Avoid keyword stuffing
- Prioritize user intent
