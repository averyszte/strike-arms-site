# Dashboard Skill

## Dashboard Philosophy
Admin dashboards should be simple, scalable, and efficient.

## Layout
- Sidebar navigation
- Clear hierarchy
- Responsive layout
- Quick access to key actions

## Features
- Role-based access
- Loading states
- Error handling
- Search/filter systems
- Efficient data tables

## Performance
- Avoid unnecessary polling
- Minimize Supabase requests
- Use pagination where needed
- Optimize rendering

## UX
- Keep actions obvious
- Avoid cluttered admin screens
- Use clear labels
- Prioritize speed and usability
