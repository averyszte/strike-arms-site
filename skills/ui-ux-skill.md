# UI/UX Skill

## Design Philosophy
- Premium but approachable
- Design direction depends on the Replit demo and client brand
- Conversion-focused
- Mobile-first
- Clean spacing
- Strong visual hierarchy

## Layout Rules
- Avoid clutter
- Use whitespace intentionally
- Keep sections visually distinct
- Maintain readable typography
- Avoid overwhelming users

## Navigation
- Sticky headers where appropriate
- Clean mobile navigation
- Keep CTA buttons visible but not intrusive

## Components
- Consistent card styling, but do not overuse cards
- Consistent button hierarchy
- Smooth hover states
- Responsive grids
- Maintain accessibility

## Things To Avoid
- Generic SaaS sections
- Excessive gradients
- Excessive animations unless they clearly fit the brand and improve UX
- Tiny text
- Crowded headers
