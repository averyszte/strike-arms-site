# Strike Arms Airsoft

A premium homepage demo for Strike Arms Airsoft — Dublin's specialist airsoft store. Designed as a catalog-grade storefront with strong conversion focus.

## Run & Operate

- `pnpm --filter @workspace/strike-arms run dev` — run the homepage (proxied at `/`)
- `pnpm --filter @workspace/api-server run dev` — run the API server (port varies)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite, Tailwind CSS, framer-motion, lucide-react, wouter
- UI: Radix UI primitives (accordion, dialog, etc.)
- API: Express 5 (shared api-server artifact)
- DB: PostgreSQL + Drizzle ORM (not yet used — homepage is static)
- Build: Vite (static output)

## Where things live

- Homepage: `artifacts/strike-arms/src/pages/Home.tsx`
- Components: `artifacts/strike-arms/src/components/` — one file per section
- Theme/CSS: `artifacts/strike-arms/src/index.css` — dark tactical theme
- Images: `artifacts/strike-arms/public/images/` — AI-generated product/lifestyle images
- API server: `artifacts/api-server/src/`

## Architecture decisions

- Homepage-only demo, all data static/hardcoded — no backend calls yet
- Dark theme applied via CSS custom properties at `:root` level (always dark)
- Hero section video-ready: background area commented for MP4/WebM swap
- All future page links (`/shop`, `/categories/*`, `/repairs`, etc.) are placeholder hrefs
- Images generated by AI and served from `/public/images/` as static assets
